# 开发与校验

本部分收录构建与发布工具链、模块边界与状态所有权以及校验命令。条目面向维护者,判据是每条都能对应到仓库内的文件、命令或校验项。

面板与 Discourse 之间的行为契约属于[Discourse 适配](../discourse/README.md),面板自身的实现契约属于[信息流行为](../feed/README.md)。
