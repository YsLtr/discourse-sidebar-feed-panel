# 迁移基线契约

2.2.3 单文件脚本被迁移为 TypeScript 模块。迁移期间冻结的一组行为构成对照契约:任何改动若改变下列基线,必须同一次显式重建基线并在提交信息中说明理由。

**事实来源**:`tests/unit/migration-parity.test.ts`、`tests/fixtures/2.2.3.behavior.json`、`tools/capture-migration-baseline.mjs`。

## 目标

- 提供一个可执行的旧版行为对照,使模块化改动可以被判定是否改变了既有行为。
- 冻结项覆盖常量、存储键、样式结构、文案与 33 个旧版函数。

## 非目标

- 把冻结范围扩展到全部实现细节:函数重命名、移入类方法与共享辅助函数不以同名函数数量判定等价。
- 以构建包行数或体积作为验收门槛:打包会改变空行、注释、函数格式与模块边界。

## 一、基线身份

- 基线取自提交 `47794f3` 的 `discourse-sidebar-feed-panel.user.js`,业务版本 2.2.3。
- 该文件 SHA-256 为 `ecd29ecbf502126827b190f60ac6dee963be8a7412c8b2c8b1589f15be39e572`。
- 冻结夹具记录来源提交与完整源码哈希;`node tools/capture-migration-baseline.mjs` 可在含历史提交的仓库重新提取。常规测试运行不依赖 Git 历史,浅克隆可直接执行。

## 二、冻结项

- `src/constants.ts` 与 `src/storage-keys.ts` 的导出集合与取值逐字不变。
- `src/styles/feed.css` 的结构签名不变:规则顺序、选择器、声明与 `!important` 保持,注释与排版不计。
- `src/i18n.ts` 的 `I18N` 词表、`getUiLocale`、`t` 与 `formatRelativeTime` 逐字同基线。
- 33 个基线函数与旧实现等价,名单由 `tools/capture-migration-baseline.mjs` 维护。

规则:

- 需要新增存储键、改变缓存版本常量、新增 UI 文案或新增 CSS 规则时,必须同一次重建对照基线并说明理由。
- 标题渲染不在 33 个冻结函数之内,可以改动;`dir="auto"` 以属性实现,不新增 CSS 规则。

## 三、与旧文档不一致的行为

下列四条以旧实现为准,`CONTEXT.md` 已按实际行为修正:

- Incoming 候选累计用于提醒计数,详情拉取上限为一页;不按保留数量截断。
- 自动刷新门槛不含「保留容量三倍」判断;旧实现只判断页面不可见/闲置与实际位于信息流起点。
- Away 从超过一屏进入并闩锁到真正回到 **Feed Head**;自动刷新门槛更严格,要求 `scrollTop <= 1`。
- 已读/未读筛选为本地操作,保留保留深度;分类、排序与周期变化才重新加载。

## 四、复现方式

```sh
npm run typecheck
npm test
npm run check:dev
npm run build
python -m pip install -r requirements-dev.txt
npm run check:artifact
npm run check:browser
npm run check:scroll -- --label migration-audit
```

- 迁移对照测试执行旧版函数的实际结果;DOM 渲染等副作用仅在数据对照中桩替代。
- 断言不得放宽以迁就实现;确需改变基线时重建夹具并说明理由。

## 五、风险

- 冻结项只覆盖被列入的基线,未列入的实现细节由常规单元测试与浏览器检查覆盖;冻结项通过不等于全部行为等价。
- 夹具依赖从 Git 历史提取的源码文本;若历史被改写,重新提取会得到不同基线,故夹具须记录来源提交与哈希。

## 六、开放问题

- 已核对:上述冻结项与四条行为差异均对应可执行的测试或明确的源码出处。
- 未核对:真实脚本管理器的升级保留行为;真实站点的长驻与唤醒;物理触摸设备。以上属发布前人工核对项。
