# Discourse 适配

本部分收录面板与 Discourse 之间的契约:侧边栏宿主的定位与宽度链路、页面语言与字段归属、跨站支持范围、消息总线订阅与主线程成本归属。适配层实现位于 `src/platform/` 与 `src/site/`,本部分的条款约束该层的对外行为。

本部分不含面板自身的阅读状态、保留数量与滚动规则,那些条款属于[信息流行为](../feed/README.md)。

## 下辖文件

- [01-页面结构与侧边栏宽度](01-页面结构与侧边栏宽度.md):宿主与页头锚点的候选链、`--d-sidebar-width` 宽度链路、写入与还原规则、验收断言与已知边界。
- [02-网页语言兼容](02-网页语言兼容.md):服务端语言解析链、`fancy_title` 字段归属、按页面语言分版本的持久缓存、语言变化的运行时侦测。
- [03-跨站适配范围](03-跨站适配范围.md):内置 match 清单、站点身份、分类来源与非目标范围。
- [04-消息总线与主线程成本](04-消息总线与主线程成本.md):订阅位置语义、`-1` 订阅对站点位置的覆盖、站点长任务的成本归属与输入时延结论。
